# asultd.com

Static one-page publication site for the **Intergenerational Goal Continuity and Social Evolution Theory**, authored by Toby William Duffield and published under the ASUKSystems identity.

## Uploading to GitHub

Upload the following items to the root of the `asultd.com` repository:

- `index.html`
- `styles.css`
- `CNAME`
- `robots.txt`
- `sitemap.xml`
- the complete `assets` folder
- `README.md`

Keep the directory structure unchanged.

## Publication date check

The page currently states:

- Initial written formulation: **12 July 2026**
- Website publication: **21 July 2026**
- Version: **1.0**

Only publish with the 21 July 2026 date if the website genuinely becomes publicly accessible on that date. If it goes live on a different date, replace every occurrence of:

- `21 July 2026`
- `2026-07-21`

in both `index.html` and `sitemap.xml` with the actual publication date.

The weekday was intentionally omitted because 21 July 2026 is a Tuesday, not a Saturday.

## Privacy decision

The supplied date of birth was not placed on the public website. A full date of birth is unnecessary for establishing authorship and creates avoidable identity and privacy risk.

## Accuracy and positioning

The page describes the material as a **developing theory** and **preliminary investigation**, not a proven scientific finding.

The copyright notice protects the site's original written and visual expression. It does not claim ownership of abstract ideas, facts, general subject matter or independently created research.
